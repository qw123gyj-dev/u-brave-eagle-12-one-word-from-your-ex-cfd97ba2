# One Word From Your Ex

Exactly one word — the word my ex would use to describe me, and nothing else. `main.ts` (Node 22, stdlib only, no network) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single word of 1 to 24 characters with no whitespace or punctuation, reads it back and verifies the bytes match.
